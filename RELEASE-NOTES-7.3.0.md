# AIAP Platform v7.3.0

## Member operations
- Advanced directory filters: member type (including Student), membership status, city, field of study, and association role.
- Global directory statistics: total records, students, cities, and fields of study.
- Print filtered directory with AIAP logo, photos, member IDs, city, field, association role, status, and global statistics.
- CSV export includes association role.
- View full member dossier with Personal, Professional/Education, Association and Account information.
- View modal now includes Close and Edit Member actions.
- Edit member profile from the directory or dossier.
- Individual Delete action for ordinary MEMBER accounts, protected by confirmation and financial-history safeguards.
- Official association accounts cannot be deleted from the member directory.
- Member status management: Super Admin, President and Secretariat.

## Events
- Edit existing events.
- Delete events with confirmation.
- Role-based API enforcement for Super Admin, President, Secretariat and Communication.

## Announcements
- Edit existing announcements.
- Delete announcements with confirmation.
- Role-based API enforcement for Super Admin, President and Communication.

## UX
- Global three-second action toast notifications retained and extended for new mutations.
- AIAP branding and orange/white/green identity retained across management surfaces.

## Database
- No Prisma schema migration required for v7.3.0.
