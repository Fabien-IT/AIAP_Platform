# AIAP Platform v8.5.13

## Simplified role-based overview
- Removed duplicated membership/community-intelligence panels from the main overview.
- Each role now receives a focused overview with only metrics relevant to its work.
- President and Vice President: active members, student/non-student composition, pending registrations, announcements.
- Secretariat: active members, pending registrations, students, non-students.
- Treasurer: income, expenses, balance.
- Communication: published activities, participants, memories, published events.
- Event Organizer: upcoming events, event plans, overdue tasks, activity participants.
- Coordinator: assigned-city members, city students, city non-students, upcoming events.
- Super Admin: system-focused overview; Super Admin remains excluded from association membership counts.
- Added a simple reconciliation showing Students + Non-students = Active members.
- Workspace navigation shows only modules authorized for the current role.
