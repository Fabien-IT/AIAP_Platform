# AIAP deployment checklist

## Frontend
Deploy `client` as a Vite static site. Set:

`VITE_API_URL=https://YOUR-API-DOMAIN/api`

The PWA manifest/service worker are generated by `vite-plugin-pwa` during build.

## Backend
Deploy `server` as a Node service. Set:

- `DATABASE_URL`
- `JWT_SECRET`
- `CLIENT_ORIGIN`
- `PORT` (provided by most hosts)
- `NODE_ENV=production`
- `SEED_ADMIN_PASSWORD` only during initial controlled seeding

Run Prisma generate/migrations as part of deployment.

## Database
Use PostgreSQL. Enable automated backups and point-in-time recovery when the chosen provider supports it.

## Media
The current API accepts validated media URLs. For production, connect the activity/document upload UI to object storage (Cloudinary, Supabase Storage, S3-compatible storage, etc.) and store only the resulting URL/key in PostgreSQL.

## Security before public launch

- Replace all development secrets.
- Remove or disable seed credentials after initialization.
- Add email verification and password reset.
- Add rate limiting at the API/edge.
- Configure exact CORS origin.
- Add monitoring/error tracking.
- Review privacy consent and data retention.
- Verify backups and restore procedure.
- Run dependency audit and application security tests.
